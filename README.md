# 🇵🇰 UrduMate AI — Pakistan’s Free AI Assistant

> **"Your Language. Your Work. Made Easier."**  
> A fast, privacy-first bilingual productivity tool built for students, freelancers, job seekers, and professionals in Pakistan. No subscriptions. No paid APIs.


## ⚡ Core Features

* 🌐 **AI Translation Studio** — Fast bi-directional English ⇄ Urdu translation with authentic **Noto Nastaliq** typography and RTL display.
* 💼 **Career & Proposal Hub** — Generate winning Upwork bids, Fiverr gig replies, job cover letters, and LinkedIn networking notes.
* ✨ **Writing Polisher & Tone Tuner** — Fix rough drafting, remove internet slang, and format text into Corporate Formal, Concise, or Bullet Points.
* ✉️ **Professional Email Writer** — Draft sick leave requests, job follow-ups, and meeting agendas in seconds.
* 🗣 **Roman Urdu Workplace Helper** — Convert casual Roman Urdu chats (e.g., *"sir kal me office nahi aaskta"*) into polished corporate English.
* 🔧 **Text Utilities Studio** — Deterministic extra space trimming, uppercase/lowercase converters, character counters, and `.txt` file export.
* 📄 **Template Vault** — Standard office applications and business communication formats served directly via FastAPI.
* 🔒 **Dual-Engine Privacy** — Fast backend processing paired with client-side Web Worker model capability (`NLLB-200`) so sensitive text remains private.

---

## 🛠 Tech Stack

* **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS v4, Lucide Icons
* **Backend:** Python, FastAPI, Pydantic, Uvicorn
* **AI & NLP:** In-browser Transformers.js (Web Workers) & direct lightweight translation pipelines
